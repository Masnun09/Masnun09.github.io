## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `Masnun09.github.io` (if that username is available for your account).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The address will normally be `https://Masnun09.github.io/`.

If GitHub does not allow that repository name, create another public repository (for example `developer-portfolio`) and enable Pages from its `main` branch and root folder. The resulting URL will include the repository name.
